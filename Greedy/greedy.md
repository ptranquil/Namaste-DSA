Greedy is a problem solving approah where we make locally optimal choices with a hope that it will lead to globally optimal solution
"Take best choice at the moment without worrying about the future"

Type of problem
1. Optimization Problem (min/max)
    - Activity selection / Interval Scheduling
    - Fractional Knapsack
    - Job sequening with deadline

2. Graph Problem
    - MST (Krusal's / Prism Algo)
    - Shortest Path

3. Scheduling Problem
    - CPU Scheduling shortest first

4. Game / Puzzle & much more

Greedy problme hint
1. Maximum number of ...
2. Min Cost / Max Profit
3. Schedule/ allocate / assign effectively
4. Shortedt / smallest / largest/ lomgest with contsrant
5. Non overlapping interval
